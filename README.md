# Rocket-Flight-Computer-and-Telemetry-Analysis
Homemade rocket project designed to save data recorded from accelerometer and gyroscope and calculated from Arduino nano esp32.
initial mass of 610 grams
powered 4 x C6-5 Estes rocket engines
Goal: design a homemade rocket using commercial solid rocket engines and computer sensor system in order to estimate trajectory and speed.
